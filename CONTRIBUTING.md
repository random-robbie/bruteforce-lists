# Contributing

Thanks for considering a contribution. Contributions are welcome from everyone.

## How to contribute

1. Fork the repository and create a branch for your change.
2. Keep pull requests small and focused — one fix or one feature per PR.
3. Explain what the change does and why in the PR description.
4. Test your change before submitting, and include reproduction steps for bug fixes.

## Reporting bugs

Open a GitHub issue with:

- What you ran (full command and output where possible)
- What you expected to happen
- What actually happened

## Reporting security issues

Do **not** open a public issue for security vulnerabilities in this tool or for
findings produced while using it. Email **rob@what-security.co.uk** instead and
follow responsible disclosure. Details will be acknowledged and credit given in
the release notes unless you prefer otherwise.

## Authorised use

Tools in this repository are for authorised security testing and research only.
Contributions must not add functionality intended to target systems the user has
no permission to test.
